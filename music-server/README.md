# Simple personal LAN music server

1. Install Python 3 on the computer that stores your music.
2. Put MP3/M4A/FLAC/WAV/OGG files in `music/`.
3. Open a terminal in this folder.
4. Run: `python server.py`
5. The terminal prints a local URL and your PC's LAN URL.
6. On your phone/laptop connected to the same Wi-Fi, open the LAN URL.

This is a basic local file server for a trusted home/college LAN. It is NOT a public internet music server. Do not expose it directly to the internet.
